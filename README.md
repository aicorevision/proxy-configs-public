# proxy-configs

Public Surge strategy and rule catalog. The private runtime profile imports only the `[Proxy]` section of the airport subscription, and imports `[Proxy Group]` and `[Rule]` from this repository. Do not put subscription URLs or node credentials here.

`Surge/CoreVision_Surge.conf` is the public strategy template. `Surge/routing.dconf` lists application rule sources; `Surge/rules/*.list` holds categorized personal matchers.
